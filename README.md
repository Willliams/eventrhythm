# EventRhythm — Ритм событий

Кликабельный HTML-макет приложения EventRhythm в псевдографическом (терминальном) стиле, адаптированный под экран телефона.

## Что внутри

Один самодостаточный файл `index.html` (HTML + CSS + JS, без зависимостей). Три экрана:

- **Главная** — список типов событий со статусом (сегментированная полоска до прогнозируемой даты) и кнопками старт/добавить.
- **Детали** — прогноз следующего события, тренд, календарная сетка с прокруткой вперёд/назад (события из истории и окно прогноза подсвечиваются автоматически).
- **Аналитика** — сводные метрики, уверенность прогноза по циклам, тренды.

Данные в макете демонстрационные (захардкожены в скрипте) — интерактивность ограничена переключением экранов и прокруткой календаря.

## Запуск локально

Открыть `index.html` в браузере — сервер не нужен.

## Деплой на GitHub Pages

1. Создать репозиторий на GitHub и запушить эту папку (см. команды ниже).
2. В репозитории: **Settings → Pages → Source: Deploy from a branch → Branch: main / (root)**.
3. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

```bash
git remote add origin https://github.com/<ваш-логин>/<репозиторий>.git
git branch -M main
git push -u origin main
```
